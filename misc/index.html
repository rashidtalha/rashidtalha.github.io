Out of the Loop (Game).

My implementation of the game Out of the Loop. I made this for my friends at NUST. There is an iOS game with the same name, but it has only one free category. To avoid paying for the full version, I decided to build it from scratch. The code is simple enough that it can be easily copied and customised.
